Founding engineer at [Nebula](https://nebula.gg), where I mostly work on the backend: the agent runtime, durable workflows, memory and app integrations. Before that I was at [thirdweb](https://thirdweb.com), building thirdweb AI.

Some of our open-source projects at Nebula:

- [fastbrowse](https://github.com/agent-labs-dev/fastbrowse): a browser agent I built that chooses actions from what's on the page and cites its answers back to page quotes. Available on [PyPI](https://pypi.org/project/fastbrowse/).
- [Bugpatrol](https://github.com/agent-labs-dev/bugpatrol): agents that explore web, desktop and mobile apps, find bugs, fix them and retest the changes.
- [electron-mcp](https://github.com/agent-labs-dev/electron-mcp): an embedded MCP server that lets agents drive Electron apps through Chrome DevTools Protocol.
- [Nebula AI skill](https://github.com/agent-labs-dev/nebula-ai-skill): teaches coding agents to use the Nebula CLI, delegate work and use connected services.

Outside of work, I make addons for WoW: Forever that fit into the game's own UI. Each works alone, and they work together. They're all on [wow.cjber.dev](https://wow.cjber.dev).

I also build [kiln](https://github.com/cjber/kiln), a compact task list for Claude Code, Codex and Pi sessions, with a paired Android app for checking activity and opening sessions from my phone.

The addons share [ForeverCore](https://github.com/cjber/forever-core), and I manage them and every other addon with [wowaddon](https://github.com/cjber/wowaddon), a command line and TUI addon manager for GitHub, CurseForge, WoWInterface, Tukui and Wago. [kiln-forever](https://github.com/cjber/kiln-forever) brings kiln's sessions into the game.

Two other tools I use every day: [keeper](https://github.com/cjber/keeper) keeps an Arch machine clean, with the agent deciding what to remove ([npm](https://www.npmjs.com/package/@cillianb/keeper), [AUR](https://aur.archlinux.org/packages/keeper)), and [deskpilot](https://github.com/cjber/deskpilot) gives agents desktop control on Hyprland without taking the user's pointer or focus ([PyPI](https://pypi.org/project/deskpilot/)).
