Founding engineer at [Nebula](https://nebula.gg), where I mostly work on the backend: the agent runtime, durable workflows, memory and app integrations. Before that I was at [thirdweb](https://thirdweb.com), building thirdweb AI.

I also built [fastbrowse](https://github.com/agent-labs-dev/fastbrowse), a browser agent that picks each action from what's on the page instead of generating it, with every claim in an answer cited back to a quote from the page. It's on [PyPI](https://pypi.org/project/fastbrowse/) if you want to try it.

I did my PhD at the University of Liverpool on NLP and geography, mainly pulling place information out of Reddit and Twitter text. The code for that is archived here if you're after it.

Most of my day-to-day work is in private repos. Outside of that I've been making addons for WoW: Forever:

- [legacy-here](https://github.com/cjber/legacy-here): your unfinished Legacy challenges on the world map, with live progress in the objective tracker
- [skillup-forever](https://github.com/cjber/skillup-forever): Classic profession-levelling numbers in the Professions window
- [ferry-forever](https://github.com/cjber/ferry-forever): every boat and zeppelin on the world map, with when the next one arrives and leaves
